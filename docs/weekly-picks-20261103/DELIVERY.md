# おすすめ3件の週替わり自動更新（2026-11-03）

先生の依頼：「『おすすめ3件』も、週替わりで記事・図解・ツールを1件ずつ選んで自動更新するようにしてください。」

同じ会話で公開したトップページへの追加変更として、自動選定・定期更新への組み込み・本番反映まで行う。

## 動作

- 公開カタログから記事・図解・ツールを1件ずつ選ぶ。対象読者が明示された候補だけを使い、記事では一般・両方向けを優先。
- 日本時間の月曜を週の区切りとし、週内は同じURLを表示する。既存の6時間ごとの定期実行で、週が変わった後の最初の成功した処理で更新する。
- 直前の掲載を優先して避け、直近8週の履歴と同じ公開記事に紐づく重複も避ける。候補の並びは週とURLから再現できる。
- 新しい候補は公開リンクを確認する。選定失敗時は前回の結果を維持し、次の処理で再試行する。カタログから削除された項目は週内でも、その項目だけを差し替える。
- 選定は `home-feed.json`、直近8週の履歴は `scripts/home_state.json` に保存する。定期処理がそのままコミット・再配信するため、追加のスケジュールは不要。
- 記事本文は書き換えず、見出しはカタログの公開タイトルを使う。説明文は形式ごとの案内。画像が無いときは形式のアイコンを表示し、画像の取得失敗も代替図柄で処理する。
- 新しいHTMLが古いJavaScriptを使わないよう、CSSとJavaScriptの読み込みURLに版を付けた。

## 運用・復旧

選定処理は `weekly_picks.py`、自動取得への組み込みは `scripts/refresh_home.py`、HTML生成は `home_sections.py`、挿入位置は `src/index.html` の `<!-- WEEKLY_PICKS -->`。

公開後は既存の `Update portal stats` を1回動かし、週内の選定が維持されることと、再配信が成功することを確かめる。

復旧する場合は、この機能の公開コミットだけを revert する。記事・カタログ・統計の後続更新は戻さない。作業はOneDrive外の独立クローンで行い、OneDrive内の既存ポータルと同期競合コピーは変更しない。
